# 🚀 HR Management Website

A modern and responsive **HR Management Website** built using **HTML, CSS, and JavaScript**. This project provides an interactive interface to manage employees, departments, attendance, leave requests, analytics, notifications, and more.

---

## 📌 Features

### 👨‍💼 Employee Management
- Add Employee
- Edit Employee
- Delete Employee
- Employee Profile Image Upload
- Search Employees
- Employee Status Management

### 📅 Attendance Management
- Interactive Attendance Calendar
- Mark Present, Absent, and Leave
- Monthly Attendance Tracking

### 📝 Leave Management
- Apply Leave Requests
- Approve Leave
- Reject Leave
- Leave Status Tracking

### 🏢 Department Management
- Add Department
- Edit Department
- Delete Department
- Department Search

### 📊 Dashboard & Analytics
- Employee Statistics
- Department Analytics
- Bar Chart
- Pie Chart
- Line Chart
- Payroll Growth Chart

### 📄 Reports
- Export Employee Data to PDF
- Export Employee Data to Excel (CSV)

### 🔔 Additional Features
- Notification Panel
- Email Notification UI
- Dark / Light Mode
- Responsive Design
- Local Storage Support
- Loading Screen
- Modern Glassmorphism UI
- Smooth Animations

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/VemireddyBhavana/hrmmanagementwebsite.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation is required.
